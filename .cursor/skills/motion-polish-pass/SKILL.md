# Motion Polish Pass

Use this skill when a Scatter block is technically working but feels flat, generic, robotic, unfinished, or disconnected from the rest of the video.

The purpose is to add the final 10% of life:
- Better staging
- Better timing
- Better easing
- Better reveals
- Better transitions
- Better holds
- Better audio sync
- Better ending poses
- Better handoff between blocks

## Core Principle

A block is not finished when all elements animate.

A block is finished when the viewer feels:
- A clear focal point
- A clear rhythm
- A clear idea
- A satisfying payoff
- A meaningful transition into and out of the scene

Do not start polish with effects.
Effects cannot fix unclear staging, bad timing, or dead transitions.

## Polish Pass Order

Always review in this order:

1. Story clarity
2. Staging
3. Timing
4. Easing
5. Overlap
6. Secondary motion
7. Transition-in
8. Transition-out
9. Texture/effects
10. Audio sync
11. Final frame
12. Responsive behavior

## 1. Story Clarity

Ask:
- What is the point of this block?
- Is this a hook, problem, reveal, proof, detail, brand beat, transition, or CTA?
- What should the viewer remember?
- Is the message readable before the next cut?
- What came before this block?
- What comes after this block?

Fixes:
- Remove unnecessary moving elements.
- Give the main idea more screen time.
- Add a hold before or after the key reveal.
- Make the main object enter first or land hardest.
- Reduce competing motion.
- Change the exit so it sets up the next scene.

## 2. Staging

Every block needs one hero.

Hero could be:
- Headline
- Product screenshot
- Logo
- Stat
- Feature card
- CTA
- Image
- Transition object
- Brand shape

Rules:
- Hero moves first or lands most clearly.
- Supporting elements move later or with less contrast.
- Decorative elements should not compete.
- Background motion should support depth, not attention.
- The transition object should not steal focus unless the block is a transition beat.

Fixes:
- Add blur/dim to background.
- Increase type scale contrast.
- Delay secondary layers.
- Use mask reveal instead of simple fade.
- Add camera push toward the hero.
- End on a clean composed frame.
- Use a foreground object to bridge into the next block.

## 3. Timing

Timing should create rhythm.

Check:
- Does everything start together?
- Does everything stop together?
- Are there enough holds?
- Are reveals too slow?
- Are exits too weak?
- Does the CTA have enough time?
- Does copy stay onscreen long enough to read?
- Does the outgoing block leave too late?
- Does the incoming block start too late?
- Is the transition cutting across an important VO word?

Recommended fixes:
- Add 2–6 frame offsets between related layers.
- Add 8–16 frame anticipation before major reveals.
- Add 12–24 frame settling after complex transitions.
- Add 40–90 frame reading holds for headline blocks.
- Make exits faster than entrances unless the exit is emotional.
- Cut on action when transitioning scenes.
- Let the next block begin 4–12 frames before the current block fully resolves when using overlapping transitions.

## 4. Easing

Bad easing makes motion feel cheap.

Default fade/slide motion is not enough.

Use brand-appropriate easing.

### Premium
- Smooth ease-out
- Long deceleration
- Minimal overshoot
- Subtle camera drift
- No cartoon bounce
- Soft dissolves or mask reveals
- Elegant match cuts

### Energetic
- Fast ease-out
- Stronger overshoot
- Snappy stagger
- Larger scale contrast
- More aggressive cuts
- Whips, pushes, snap zooms

### Editorial
- Hard cuts
- Mask wipes
- Confident type reveals
- Sharp but controlled movement
- Graphic rhythm
- Match cuts and layout-driven transitions

### Playful
- Soft bounce
- More squash/stretch
- More stagger
- Secondary details
- Higher motion contrast
- Elastic transitions, but restrained

### Tech
- Precise motion
- Crisp timing
- Subtle parallax
- Clean ease curves
- Data-driven sequencing
- UI-led match cuts

### Streetwear / Music / Grunge
- Punchy motion
- Gritty texture wipes
- Fast smash cuts
- Camera shake only when intentional
- Halftone/grain/light leak accents
- Imperfect but designed timing

Fixes:
- Replace linear motion.
- Add overshoot to key landings.
- Use separate easing for parent and child layers.
- Use ease-in for exits.
- Use ease-out for entrances.
- Avoid using the same curve everywhere.
- Make transitions use their own easing, not the same easing as internal layer animation.

## 5. Overlap and Follow-Through

Alive motion rarely stops all at once.

Add:
- Parent lands first.
- Children settle 2–5 frames later.
- Text follows container motion.
- Decorative accents trail.
- Camera finishes slightly after foreground.
- Background continues drifting subtly during hold.
- Transition wipe finishes slightly after the outgoing hero exits.
- Incoming scene begins before the transition completely clears.

Examples:
- Card enters over 18 frames.
- Image inside card settles 3 frames later.
- Badge pops 5 frames after card.
- Text counter finishes 8 frames after bar growth.
- Background gradient settles 12 frames after hero.
- Shape wipe starts 10 frames before scene cut and completes 8 frames after new scene appears.

## 6. Secondary Motion

Add one or two supporting details.

Good secondary actions:
- Underline draw
- Small badge pop
- Mask edge sweep
- Grain breathing
- Glow pulse
- Parallax drift
- Cursor highlight
- Chart tick-up
- Logo shimmer
- Texture wipe
- Tiny camera settle
- Small transition echo from previous block

Bad secondary actions:
- Random particles
- Too many sparkles
- Constant background movement
- Effects that reduce readability
- Motion unrelated to the idea
- Secondary motion that repeats identically in every block

## 7. Transition-In

Every block needs a designed entrance.

Transition-in should answer:
- Where did this block come from?
- What motion from the previous block carries into this one?
- Does the first frame feel intentional?
- Does the entrance clarify the story?
- Is this a cut, reveal, continuation, or reset?

Transition-in types:
- Hard cut
- Cut on action
- Match cut
- Mask reveal
- Push
- Pull
- Wipe
- Zoom-through
- Camera carry-through
- Object carry-through
- Texture wipe
- Glitch
- Dissolve
- Morph
- Split-screen shift
- Parallax slide

Rules:
- Do not default to fade.
- The entrance should match the energy of the previous block.
- The first 6–12 frames should make the new focal point clear.
- Avoid having the incoming scene start with everything already centered and static.
- Use transitions to create meaning, not decoration.

## 8. Transition-Out

Every block needs a designed exit.

Transition-out should answer:
- What is the last thing the viewer sees?
- Does the block resolve before leaving?
- Does the exit point toward the next block?
- Does the motion cut on action?
- Does the outgoing movement create a natural entry path for the next block?

Exit types:
- Hero object exits and pulls next block in
- Mask closes and reopens into next block
- Camera pushes through UI/image into next scene
- Text wipes into the next headline
- Background shape becomes next scene container
- Product card scales up until it becomes a full-screen transition
- Texture wipe covers frame and reveals new scene
- Data point morphs into CTA/card/logo
- Smash cut on strong beat
- Soft dissolve after emotional/brand moment

Rules:
- The block should not just stop and disappear.
- The exit should have either resolve or momentum.
- The last 8–16 frames are critical.
- Do not cut away before the key action lands.
- Do not overcomplicate exits for detail-heavy UI scenes.

## 9. Texture and Effects

Effects should be the last layer of polish.

Useful product marketing effects:
- Grain
- Glow
- Bloom
- Vignette
- Halftone
- CRT
- Shadow
- Blur
- Light sweep
- Gradient shift
- Film gate
- Chromatic edge
- Subtle distortion
- Texture wipe
- Printed ink/noise transition
- Light leak transition

Rules:
- Effects must support brand DNA.
- Effects should not hide the message.
- Post-FX should be preview-optimized.
- Export can render higher-quality effects.
- Use restraint on premium brands.
- Use more grit on expressive/streetwear/music brands.
- Effects can help transitions, but should not replace animation logic.

## 10. Audio Sync

Motion feels alive when it acknowledges sound.

Sync to:
- VO sentence starts
- VO emphasis words
- Music downbeats
- Percussion hits
- Bass drops
- Scene changes
- CTA moments
- Logo endings

Fixes:
- Land headline on beat.
- Reveal stat on emphasized word.
- Cut scene on downbeat.
- Add micro accent on snare/hat.
- Hold after important VO phrase.
- Let logo resolve with final beat.
- Start transition anticipation before the beat and land the next scene on the beat.

Avoid:
- Motion that ignores soundtrack.
- Cuts during important words.
- Over-animating while VO needs clarity.
- Looping music with no structure.
- Random beat syncing that makes the video chaotic.

## 11. Final Frame

Every block should end on a strong design frame or a meaningful handoff frame.

Ask:
- Would the final frame work as a poster?
- Is the hierarchy clear?
- Is the layout balanced?
- Is the CTA visible?
- Is text readable?
- Does the brand feel present?
- Did motion settle before the cut?
- Does the final frame prepare the next scene?

Fixes:
- Add final 8–16 frame settle.
- Reduce background activity at the end.
- Align elements to grid.
- Hold final composition longer.
- Add subtle finishing effect.
- Make ending pose more graphic.
- Use the ending pose as the starting geometry for the next transition.

## 12. Responsive Behavior

Motion must survive different aspect ratios.

Check:
- Does the hero stay visible?
- Are masks safe on 9:16 and 4:5?
- Is text readable in square?
- Does camera movement crop important content?
- Does stagger still work if layout reflows?
- Are decorative elements anchored safely?
- Does transition direction still make sense vertically?
- Does a horizontal wipe still work in portrait?
- Does zoom-through crop too much in 9:16?

Fixes:
- Use safe zones.
- Use brand grid tokens.
- Use relative motion distances.
- Reduce travel distance on mobile formats.
- Scale typography with type system.
- Allow block-level advanced overrides.
- Create transition variants for landscape, square, and portrait.

## Dead Motion Diagnosis

If a block feels dead, check for:

- Only opacity animation
- No anticipation
- No overshoot
- No follow-through
- No hierarchy
- No hold time
- No audio relationship
- No camera movement
- No secondary action
- No final landing pose
- Too many simultaneous starts
- Too many default transitions
- Same easing everywhere
- Generic movement unrelated to brand
- No meaningful entrance
- No meaningful exit
- No relationship to previous or next block

## Required Output Format

When using this skill, provide:

1. Current issue
2. Why it feels flat
3. Specific fix
4. Timing recommendation
5. Easing recommendation
6. Layer sequencing
7. Transition-in recommendation
8. Transition-out recommendation
9. Audio sync note
10. Final frame note
11. Responsive notes
