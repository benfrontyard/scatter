# Animation Life Principles for Product Motion

Use this skill when a Scatter motion block feels flat, dead, robotic, default, or too template-like.

This skill adapts the Disney 12 principles of animation into modern UI/product motion, product marketing videos, branded templates, and Remotion-based animation blocks.

The goal is not cartoon animation.

The goal is motion that feels:
- Alive
- Intentional
- Rhythmic
- Designed
- Branded
- Satisfying
- Easy to understand
- Good as part of a video sequence

## Core Rule

Every motion block should answer:

> What is the viewer supposed to notice, understand, and feel in this moment?

Motion is not decoration.
Motion is staging, pacing, hierarchy, and payoff.

If everything moves equally, nothing feels alive.
If everything enters at once, the video feels flat.
If there is no anticipation or follow-through, the animation feels mechanical.
If transitions between blocks do not connect, the final video feels like a slideshow.

## Product Motion Translation

Translate the Disney principles like this:

- Squash and stretch → subtle scale tension, compression, stretch, and elasticity
- Anticipation → pre-motion cue before a reveal, transition, or landing
- Staging → clear visual hierarchy and focal point
- Straight ahead / pose-to-pose → clear animation states plus organic secondary detail
- Follow-through → delayed settling and trailing details
- Slow in / slow out → brand-appropriate easing
- Arcs → elegant non-linear paths and camera motion
- Secondary action → supporting detail that reinforces the main idea
- Timing → rhythm, readability, and emotional pacing
- Exaggeration → clearer design intent and stronger payoff
- Solid drawing → spatial clarity, responsive composition, and depth
- Appeal → satisfying, memorable, branded motion

## The 12 Principles Adapted for Scatter

### 1. Squash and Stretch

Use subtle scale, compression, or expansion to make movement feel physical.

For product/UI motion:
- A card can slightly scale down before popping in.
- Text can compress by 1–2% before expanding into place.
- A logo can settle with tiny elastic tension.
- A shape can stretch along the direction of travel.
- A graph bar can grow slightly past its target and settle back.
- A CTA button can compress on impact before landing.

Good values:
- Subtle scale down: 0.97–0.99
- Subtle overshoot: 1.01–1.04
- Expressive overshoot: 1.04–1.08
- Premium overshoot: 1.005–1.02

Avoid:
- Big cartoon bounce unless the brand is playful.
- Rubber-like movement on premium or serious brands.
- Random scale changes with no clear force.

### 2. Anticipation

Before the main action, create a tiny preparation moment.

Anticipation makes motion feel intentional.

For product motion:
- A title shifts down 4px before rising in.
- A mask tightens before revealing.
- A card scales down to 0.98 before expanding into place.
- A camera pulls back slightly before pushing in.
- A shape gathers before wiping the screen.
- A scene darkens slightly before the product reveal.
- The outgoing block starts moving before the incoming block appears.

Use anticipation before:
- Scene transitions
- Product reveals
- Logo moments
- CTA moments
- Large layout changes
- Camera moves
- Mask reveals
- Data/stat reveals
- Important text moments

Timing:
- Micro anticipation: 4–8 frames
- Standard anticipation: 8–14 frames
- Large reveal anticipation: 12–20 frames

Avoid:
- Abrupt elements appearing with no setup.
- Every element using the same anticipation.
- Anticipation that makes the scene feel slow or mushy.

### 3. Staging

Make the important thing obvious.

Every block needs one hero action.

The hero can be:
- Headline
- Product UI
- Logo
- Stat
- CTA
- Image
- Feature card
- Brand shape
- Transition object

Ask:
- What is the focal point?
- What moves first?
- What moves strongest?
- What supports the hero?
- What should stay still?
- What should be delayed?
- What should be dimmed, blurred, cropped, masked, or simplified?

Staging tools:
- Scale hierarchy
- Type hierarchy
- Contrast
- Blur
- Opacity
- Camera position
- Masking
- Negative space
- Timing delay
- Audio accent
- Background restraint
- Grid alignment

Avoid:
- All elements entering at once.
- Multiple focal points competing.
- Background motion fighting with text.
- Decorative effects overpowering the message.
- Huge UI screenshots with no visual guidance.

### 4. Straight Ahead and Pose-to-Pose

Use pose-to-pose for most Scatter blocks.

Define key poses:
1. Start pose
2. Anticipation pose
3. Hero pose
4. Overshoot pose
5. Settled pose
6. Exit pose
7. Transition handoff pose

A block should not only have an entrance.
It should have a designed exit that prepares the next block.

Use straight-ahead motion for:
- Particles
- Grain
- Glitches
- Hand-drawn lines
- Organic textures
- Liquid movement
- Film damage
- Noise
- Background drift

For UI/product blocks:
Start with clear poses first.
Then add secondary organic motion after.

### 5. Follow Through and Overlapping Action

Not everything should stop at the same time.

Alive motion has overlap.

Examples:
- Card lands first, text settles 2–4 frames later.
- Image reveal finishes, then badge slides in.
- Main title stops, underline continues slightly.
- Camera move ends, background parallax drifts for a few frames.
- Logo settles, then small sparkle/noise/accent resolves.
- Outgoing block exits first, then texture or shape wipe finishes after it.
- Incoming block starts before the previous block is fully gone.

Rules:
- Parent object moves first.
- Child/details follow slightly after.
- Decorative elements can trail the main action.
- Exits should have stagger and drag.
- The transition object can continue moving between blocks.

Good offsets:
- Tight UI stagger: 2–4 frames
- Standard stagger: 4–8 frames
- Expressive stagger: 8–14 frames
- Large sequence stagger: 12–24 frames

Avoid:
- All layers stopping on the same frame.
- Robotic synchronized movement.
- Overlap that reduces readability.
- Secondary motion that steals focus from the main message.

### 6. Slow In and Slow Out

Use easing to create weight and intention.

Most motion should not be linear.

General easing:
- Premium: soft ease-out, restrained movement, long deceleration
- Energetic: sharper ease-out, stronger overshoot, snappy landing
- Editorial: confident cuts, hard masks, controlled easing
- Playful: elastic but not childish
- Tech: precise, crisp, fast, structured
- Streetwear/music: more aggressive, tactile, gritty, punchy

Use:
- Ease-out for entrances
- Ease-in for exits
- Ease-in-out for camera moves
- Back/overshoot for expressive brand moments
- Hold frames for readability
- Linear only for mechanical, data, or intentionally synthetic motion

Avoid:
- Same easing on every object.
- Linear movement by default.
- Springy easing on serious/premium brands.
- Slow easing that makes the video feel unresponsive.

### 7. Arcs

Movement should often travel through arcs, not perfect straight lines.

For UI/product motion:
- Cards can slide in with slight curved x/y motion.
- Camera can drift diagonally, not only zoom.
- Background assets can orbit or sweep.
- Logos can settle along a subtle arc.
- Image crops can pan with slight curve.
- Transition wipes can arc instead of moving as flat rectangles.

Use arcs when:
- Motion feels stiff.
- Transitions feel too mechanical.
- Elements need elegance or human rhythm.
- Camera movement feels flat.

Avoid:
- Random curved paths.
- Curves that distract from content.
- Excess diagonal motion in dense UI scenes.

### 8. Secondary Action

Add small supporting movement that enhances the main idea.

Examples:
- Small badge appears after a stat.
- Background gradient subtly shifts during title reveal.
- Grain breathes while image holds.
- A cursor or marker highlights the key UI area.
- Underline draws after headline.
- Chart labels tick up after bars animate.
- Mask edge has a subtle light sweep.
- Texture wipe follows the main transition.
- CTA gets a tiny pulse after landing.

Secondary action should support the hero action, not compete with it.

Ask:
- What small detail makes this moment feel designed?
- Does it clarify the message?
- Does it add brand personality?
- Does it help bridge to the next block?

Avoid:
- Random particles everywhere.
- Too many sparkles.
- Constant background movement.
- Effects that make text harder to read.

### 9. Timing

Timing controls emotion.

Fast is not always exciting.
Slow is not always premium.

Use timing to create:
- Snap
- Confidence
- Suspense
- Reveal
- Impact
- Breath
- Rhythm
- Clarity
- Payoff

Recommended timing ranges at 30fps:
- Micro interaction: 6–12 frames
- Text word entrance: 8–18 frames
- Card entrance: 12–24 frames
- Major reveal: 18–36 frames
- Scene transition: 12–30 frames
- Camera move: 24–60 frames
- Reading hold: 40–120 frames
- CTA hold: 60–120 frames
- Logo resolve: 30–90 frames

Rules:
- Important ideas need hold time.
- Fast motion needs clear staging.
- Complex UI needs slower reveals.
- Simple bold graphics can move faster.
- Motion should land on music/VO beats when possible.
- Transitions should not interrupt key words in VO.
- Exit timing should prepare the next scene.

### 10. Exaggeration

Push the idea enough that the viewer feels it.

For product motion, exaggeration is usually controlled:
- Bigger contrast
- Clearer scale jump
- Stronger mask reveal
- More decisive camera move
- Sharper timing
- Larger type hierarchy
- More dramatic hold
- More obvious transition handoff

Use exaggeration when:
- Motion feels invisible.
- Reveal lacks impact.
- CTA does not land.
- Stat needs emphasis.
- Ending feels weak.
- Block transition feels like a default cut.

Avoid:
- Over-animating every detail.
- Huge bounce on premium brands.
- Exaggeration that breaks brand trust.
- Visual noise that reduces comprehension.

### 11. Solid Drawing

In Scatter, this means spatial clarity and visual structure.

Every frame should feel composed.

Check:
- Are objects aligned to a clear grid?
- Does depth make sense?
- Is the camera move understandable?
- Are foreground, midground, and background separated?
- Does the layout work in 16:9, 1:1, 4:5, and 9:16?
- Is text readable during motion?
- Does motion preserve brand hierarchy?
- Does the exit pose give the next block a clean entry?

Avoid:
- Floating elements with no structure.
- Random placement.
- Motion that breaks responsive layouts.
- Depth effects that make UI illegible.
- Transition paths that crop important content.

### 12. Appeal

Appeal is the final test.

A block has appeal when it feels:
- Clear
- Designed
- Branded
- Rhythmic
- Satisfying
- Memorable
- Not generic
- Good in a sequence

Appeal can come from:
- Beautiful easing
- Strong composition
- Confident typography
- Good contrast
- A satisfying reveal
- A tiny unexpected detail
- Strong ending pose
- Brand-specific motion behavior
- A transition that feels motivated

Ask:
- Would this look good as a GIF?
- Would a motion designer save this as inspiration?
- Does the final frame feel poster-worthy?
- Does the movement match the brand personality?
- Does the block feel alive without feeling gimmicky?
- Does the block make the next block feel more exciting?

## Common Dead Motion Problems

Motion feels dead when:
- Everything fades in.
- Everything slides from the same direction.
- All layers start and stop together.
- There is no overshoot.
- There is no anticipation.
- There is no follow-through.
- There is no hierarchy.
- The camera never moves.
- The edit has no rhythm.
- Text appears without personality.
- Transitions feel like default presets.
- Nothing reacts to music or VO.
- Final frame has no designed landing pose.
- Each block feels isolated from the next one.
- Scene changes feel like a slideshow.

## Required Review Questions

When reviewing a block, answer:

1. What is the hero action?
2. What should the viewer notice first?
3. Does the motion have anticipation?
4. Does the main action have weight?
5. Does anything follow through after the main action?
6. Are there staggered layers?
7. Is the easing brand-appropriate?
8. Does movement follow arcs or feel robotic?
9. Is there a secondary action that adds polish?
10. Does the timing match the music, VO, or edit rhythm?
11. Does the final frame feel composed?
12. Does the exit pose prepare the next block?
13. Does the transition into the next block feel motivated?
14. Does the block have appeal?

## Output Format When Using This Skill

When improving a block, respond with:

- Diagnosis
- What feels dead
- Motion principle fixes
- Specific timing changes
- Specific easing changes
- Layer-by-layer animation notes
- Transition-in notes
- Transition-out notes
- Audio/beat sync notes
- Final polish checklist
